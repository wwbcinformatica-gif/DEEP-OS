Capacidades Principais

Memoria Espiral

Sistema de memoria em multiplas camadas: elastica (sessao), vetorial (FAISS), cerebro (aprendizado). Persiste conhecimento entre sessoes com consolidacao automatica.

Persistente

Maquina de Estados

Agentes seguem ciclo determinista: planejar, executar, verificar, aprender. Circuit breakers anti-loop previnem recursao infinita.

Automatizado

Multi-Provedor LLM

Alterne entre Ollama, Groq, OpenCode, MiMo, Gemini e OpenAI. Roteamento por agente com cadeia de fallback.

7 Provedores

Chamada de Ferramentas

Explorador de arquivos, terminal, busca de codigo, executor Python, busca web. Agentes usam ferramentas autonomamente.

12+ Ferramentas

Controle por Voz

Web Speech API para entrada de voz em PT-BR. Edge TTS para saida de voz. Auto-envio, auto-reinicio, design de acessibilidade.

Acessibilidade

Gerenciamento de Tarefas

Checklists dinamicos com progresso em tempo real. Tarefas rastreadas via SSE com eventos task_plan e task_progress.
