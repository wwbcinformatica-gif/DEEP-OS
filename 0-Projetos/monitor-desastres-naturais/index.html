APIs Utilizadas

Dados em tempo real provenientes das principais agências de monitoramento mundial

USGS Earthquake API

Dados sísmicos em tempo real do Serviço Geológico dos EUA. Atualização contínua a cada minuto.

earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson
Real-time Gratuita GeoJSON

NASA EONET

Eventos naturais monitorados por satélites da NASA: vulcões, incêndios, tempestades e mais.

eonet.gsfc.nasa.gov/api/v3/events
Near Real-time Gratuita JSON

GDACS

Sistema de Coordenação de Alertas de Desastres Globais da ONU. Alertas de terremotos, ciclones, enchentes e vulcões.

www.gdacs.org/gdacsapi/api/events/getevent
Real-time Gratuita JSON/XML

ReliefWeb API

Plataforma humanitária da ONU com relatórios e dados de desastres de fontes confiáveis mundiais.

api.reliefweb.int/v1/disasters
Atualizado Gratuita JSON
